Windows 首次运行会弹「Windows 已保护你的电脑」
这是未签名程序的正常提示，点「更多信息」→「仍要运行」。 原因是要代码签名证书（每年几百美元），个人项目没有。

右键点程序 → 打开 → 确认。或在「系统设置 → 隐私与安全性」里点「仍要打开」。

怎么用

  1. 打开程序，填入 GitHub Personal Access Token（需要 repo 权限）
  2. 令牌只存在本机配置文件，不上传任何服务器
  3. 登录后自动扫描账号下的 drive-storage-* 仓库并列出文件

没有令牌？ GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token

和网页版是什么关系

数据格式完全兼容，双向。网页版传的文件，桌面版打开就能看见、能下载；反之亦然。

做桌面版是为了补上网页版做不到的事：浏览器沙箱里碰不到文件系统、 起不了进程，所以「同步到本地目录」「下载完自动调用本地工具」这类需求 只能靠桌面版。这是新生态，不是移植。

契约约定
分片路径{base36(毫秒时间戳)}/{文件名}
分片大小512 KB
存储仓drive-storage-{日期}-{4位hex}（私有）
配置仓github-drive-config（与网页版共用）
分享仓gd-share-{6位hex}（公开 + Pages）

插件

桌面版插件是 Python，能读写本地文件、调用外部程序 —— 与网页版插件不兼容，也不打算兼容（网页插件跑在沙箱里，本来就没这些能力）。

权限风险
fs:read / fs:list低
net中
fs:write高
exec⛔ 极高（等于把终端交出去）

官方插件免确认，第三方插件安装时弹权限清单。 授权之后运行时每次调用仍会校验 —— 否则插件 A 能冒充插件 B， 权限模型就形同虚设。
